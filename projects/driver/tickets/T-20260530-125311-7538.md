## Description

Move first-run admin creation into a repository-level atomic operation so concurrent setup requests cannot create more than one first admin.

## Acceptance

- Memory and Postgres repositories expose an atomic create-first-admin operation or equivalent transaction.
- Concurrent setup tests prove only one admin is created and other requests receive conflict.
- Existing setup status and login behavior remains compatible.
- Error mapping distinguishes conflict from invalid user input.
