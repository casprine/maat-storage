## Description

Add health checks and diagnostics for helper services such as translation and embeddings so outages are visible before or during processing instead of surfacing as opaque job failures.

## Acceptance

- Translation and embedding endpoints have health-check logic with bounded timeouts.
- Health status is exposed through protected/admin API without leaking API keys or full secret URLs.
- Worker and API behavior remains non-fatal when optional helper services are unavailable.
- Tests cover healthy, unhealthy, timeout, and disabled-provider cases.
