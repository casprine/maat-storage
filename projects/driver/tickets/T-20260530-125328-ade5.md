## Description

Prevent optional embedding-provider outages from breaking ordinary keyword search by falling back to repository keyword search when query embedding fails.

## Acceptance

- Configured embedding search still uses vector ranking when embedding succeeds.
- Embedding provider errors are logged or surfaced as non-fatal diagnostic information without leaking secrets.
- Keyword search results are returned when embedding generation fails.
- Tests cover success, provider failure, and empty query behavior.
