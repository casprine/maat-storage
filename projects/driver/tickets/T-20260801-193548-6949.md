## Description

Teach the worker watcher/reconciler to ignore TrueNAS, Synology, recycle-bin, snapshot, and metadata junk files while preserving path-safety and per-file error isolation.

## Acceptance

- Default ignore patterns cover common NAS/system files such as @eaDir, ._*, #recycle, #snapshot, .stversions, and .stfolder.
- Ignored files do not enqueue jobs and are represented in diagnostics or logs where useful.
- Path safety, symlink behavior, and healthy-file continuation remain unchanged.
- Focused worker tests cover ignored files, nested ignored folders, normal files, and bad-file isolation.
