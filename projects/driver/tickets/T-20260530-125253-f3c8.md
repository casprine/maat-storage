## Description

Carry worker processing StepResult data through job completion/failure into API persistence so document detail/events show inspection, preview, extraction, chunking, language, translation, and embedding outcomes.

## Acceptance

- Worker completion/failure payloads include structured step results without leaking filesystem paths in user-facing protected responses.
- API persists step results as document events or structured job-step records with useful messages and statuses.
- Document detail/events expose enough timeline data for troubleshooting translation and embedding partial failures.
- OpenAPI and generated SDK are synchronized for any contract changes.
- Tests cover partial translation, partial embedding, unsupported extraction, and successful indexing timelines.
