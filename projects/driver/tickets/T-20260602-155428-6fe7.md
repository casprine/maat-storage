## Description

Implement Goal 6 from docs/translation-artifacts-plan.md: translation artifact metadata versioning, stale/current invalidation, and a narrow worker reprocess path without implementing sidecar, language detection, Markdown, overlay PDF, or broad artifact UI.

## Acceptance

- Translation artifacts record provider name, provider metadata, target language, artifact schema version, and overlay renderer version placeholders where applicable.
- Processing marks existing translation artifacts stale when target language or provider metadata changes, so old artifacts cannot masquerade as current translations.
- A document can be reprocessed through a focused worker/API action or equivalent smallest viable trigger after translation model or language changes.
- Focused tests cover current artifacts, stale artifacts, and reprocessing behavior.
