## Description

Implement the worker-side v1 masked overlay PDF artifact for translated PDF chunks: capture/represent reliable page text geometry when available, generate a separate translated.pdf artifact with masking and translated overlay, and record explicit metadata for skipped or failed boxes without modifying the original source file.

## Acceptance

- PDF geometry boxes are represented with page coordinates, confidence, font hints, and source chunk linkage when capture succeeds.
- Translated PDF artifact generation writes under app data and never mutates the original PDF.
- Boxes that cannot be overlaid or fitted are recorded in translated-artifacts.json with explicit reasons.
- Focused worker tests cover successful overlay metadata and geometry-unavailable failure metadata.
