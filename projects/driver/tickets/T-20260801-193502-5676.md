## Description

Implement local embeddings as one coherent feature: model-aware embedding provider metadata, dimension checks, optional Docker sidecar, configuration/settings surface, and stale/reprocess behavior for changed embedding models.

## Acceptance

- Embedding model/provider metadata includes model name, provider, dimension, and version/hash where available.
- Driver rejects or safely skips embeddings whose dimensions do not match the configured database/vector model state.
- Compose and env examples can run an optional local embedding endpoint without requiring cloud credentials.
- Settings or API configuration can choose disabled, external endpoint, or local sidecar mode without leaking secrets.
- Changing embedding model marks prior embeddings stale or exposes a safe reprocess path.
