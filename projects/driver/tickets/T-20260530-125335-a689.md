## Description

Make worker reconciliation isolate unreadable or problematic file failures so one bad file does not stop the always-on watcher from reporting other stable files.

## Acceptance

- Walk, stat, checksum, and handler failures for one file are represented as per-file diagnostics or skipped events when safe.
- Healthy files in the same scan are still registered or deleted when another file fails.
- Symlink and path-safety behavior remains unchanged.
- Tests cover unreadable/stat/checksum failure scenarios and prove continued scanning.
