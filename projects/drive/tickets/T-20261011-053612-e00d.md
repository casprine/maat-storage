## Description

[A4, owner: api, slice S2] PATCH /documents/{id} changes the display title only (nothing is renamed on disk). POST /documents/bulk takes ids and an action (move, trash, restore, tag-add, tag-remove, collection-add, collection-remove) and returns per-id results. GET /documents/{id}/original sends an attachment. POST /documents/download streams a zip of selected documents. Needs: A0. Read docs/design-support-plan.md first; stay inside your area and migration range.

## Acceptance

- Bulk actions report partial failures per id and never leave a half-applied item
- Zip and original downloads stay behind auth and respect grants
- Originals on disk are never modified
