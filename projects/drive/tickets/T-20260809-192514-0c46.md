## Description

Provide a duplicate-review page and a deliberate merge action that lets the user choose one source file to keep while moving the other identical source files to the operating system Trash.

## Acceptance

- The API lists duplicate source groups without exposing paths in ordinary document responses.
- A protected merge action validates a selected surviving source, moves every other duplicate source to the operating system Trash, and leaves the canonical document usable.
- The web app exposes a Duplicate copies page where the user can select the retained file and confirm the destructive merge.
- Relevant API and web validations pass.
