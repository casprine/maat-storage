## Description

Add a route-level authentication boundary so Drive application pages require a persisted session, while the authentication page remains public.

## Acceptance

- Unauthenticated visits to application routes redirect to the public auth route.
- Authenticated users can access existing application routes and do not see the auth screen.
- The app has one dedicated public authentication route.
