## Description

Extend the auto-tagging product so users and the pipeline can attach, review, and manage tags on logical folders, with provenance and access controls appropriate to folder context.

## Acceptance

- Folder tags can be created, attached, listed, and removed through authenticated backend contracts without exposing filesystem paths.
- The persistence model records source, review state, and audit metadata for folder assignments, or deliberately generalizes the document assignment model before deployment with a tested migration/reset strategy.
- Automatic folder tagging uses bounded aggregate context and never blocks document ingestion or mutates original files.
- The web taxonomy and review experience distinguishes document and folder assignments.
