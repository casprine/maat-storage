## Description

Detect unambiguous checksum-preserving physical moves inside the watched directory and update the existing ingestion source atomically, avoiding deletion status churn and reprocessing.

## Acceptance

- A same-content move inside the watched root preserves the document ID, indexed status, and processing artifacts without enqueueing a new job.
- True deletions still become deleted after a bounded grace window, and ambiguous equal-content paths fall back safely.
- Targeted reconciler and API integration tests cover moved, deleted, and ambiguous paths without leaking filesystem paths.
